# 开源许可决策（待确认）

GitHub 仓库公开可见不等于开源授权。第一阶段刻意不生成 LICENSE 文件，以免擅自替项目所有者决定授权范围。

可选：

- **软件**：MIT / Apache-2.0 / GPL-3.0（需按实际整合方式处理第三方代码）。
- **硬件设计**：CERN-OHL-S-2.0 / CERN-OHL-P-2.0 等适合硬件图纸的许可。
- **文档**：CC BY 4.0 / CC BY-SA 4.0。

OnStepX 上游使用 GPL 授权，若复制/修改再分发相关代码，应遵循对应许可证，保留版权与授权信息。最开始可以通过注明上游版本与链接的方式做兼容配置仓库，不直接发布其源码。
