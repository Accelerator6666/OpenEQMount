## 载荷数学模型

沿用 V1.4 的坐标：相机接口面 z = 75 mm；CG z = 75 + 距离（mm）；4 kg，距接口面 80 mm，则 z = 155 mm，F = 39.2266 N。

简化悬臂两点支撑示意，两个理想径向支撑位置 a、b：

- 两点中心距 L = b − a。
- 远侧同向反力绝对值 = F × (z − a) / L。
- 近侧反向反力绝对值 = F × (z − b) / L。

| 假设的支撑 | 中心距 | 同向支撑反力约 | 反向支撑反力约 |
|---|---:|---:|---:|
| 6808 原位置：z = 10.5 与 40.5 mm | 30 mm | 189 N | 150 N |
| 7008 设想位置：z = 7.5 与 57.5 mm | 50 mm | 116 N | 77 N |
| RU66 单体：单件外形 z = 20..35 mm | 非两支点模型 | 不适用 | 不适用 |

以上反力值是**抽象两支点外部反力**，不是角接触滚珠的内部接触反力。实际 7008 的有效支撑跨度取决于接触角、配对方式及有效载荷中心；**把几何中心间距 50 mm 当成有效跨距只是一种示例，不构成实际刚度更高的证明**。RU66 需要厂家给出允许力矩、挠度及安装刚度等计算路径；不能将单一 RU66 机械地代入两点支撑公式。

## DfAM 与安全关闭条件

V1.5 三件 PETG 公差检具为纯粹的**非承力打印片**，XY 平放；禁止打印机壳、承载轴、轴承压盖作为塑料受力件。Gate A 仅网格及资料检查，Gate B（切片/真实尺寸）和 Gate C（结构/转动精度/冲击/防坠/带载）未进行。

进入 V1.6 前必须：

1. 测定相机机身、镜头、镜头脚、夹具的实际质量、CG、安装面及光轴高度，确认最坏姿态。
2. 对 7008 获取 **准确匹配双列方案**：DB/DF、接触角、实际轴向刚度、预紧等级、温度补偿、制造等级、配合/锁紧螺纹及厂家安装图。
3. 对 RU66 获取 **OEM 原厂型号图和力矩刚度规格**，全面重画 Ø35 转轴及相关孔系，核对 0.62 kg 附加重量。
4. 对所有候选建立真实装配剖面及装入路径、紧固件扭矩、服务空间及防松；独立金属防坠和相机侧实际锚点另行验证。
5. 通过 Gate B、Gate C 后才能讨论通电或使用相机；目前的通过不具备任何现场安全含义。
