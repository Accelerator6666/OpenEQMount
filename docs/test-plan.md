# 逐阶段测试计划

| 阶段 | 条件 | 产出 |
|---|---|---|
| M0 数学/架构 | Python 单元测试通过；传动参数来源清楚 | CI 通过 + 设计记录 |
| M1 单轴台架 | 空载运行；方向/速度/停车/错误处理 | 视频、日志、驱动温度 |
| M2 双轴台架 | 独立 RA/DEC、回零传感器、软件限位 | 回零重复性、停止记录 |
| M3 机械样机 | 无镜筒及模拟配重负载；断电/意外停止演练 | 故障模式记录、图纸修订 |
| M4 天文兼容 | ASCOM/INDI 连接；GoTo 与导星命令响应 | 软件版本、通信日志 |
| M5 实星验证 | 标明载荷、镜筒焦距、环境、极轴校准方式 | PHD2 导星日志、RMS、周期误差曲线 |

**重要**：步进分辨率是理论命令分辨率，不是实测导星精度。禁止在失控/掉电风险尚未消除时直接挂载贵重设备。
