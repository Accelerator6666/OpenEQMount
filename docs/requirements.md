# V1 需求与验收基线（草案）

## 已决定/待确认

- 默认方向：德式赤道仪（GEM），RA、DEC 双轴，GoTo + 恒星跟踪 + 外部导星。
- **待用户确认**：相机/望远镜总质量（含导星镜、寻星镜、平衡块以外配件）；最长焦距与镜筒长度；预算；加工能力；是否必须无配重；是否便携。
- **目标载荷：3–5 kg（研发指标，未验证）**；需要把 *载荷质量* 与 *有效力矩/偏心* 分开评价。

## 功能性需求

- RA：恒星时连续跟踪（必选）；太阳时/月球时可选。
- 两轴 GoTo，支持运动加减速并能够正确处理坐标、安装方向与机械边界。
- 回零传感器、软件行程限位、实体运动范围确认、Park/Unpark。
- 手动紧急停止，驱动异常停止，不因复位自动恢复高速移动。
- 支持标准天文软件；第一阶段使用 OnStepX 生态 ASCOM/INDI 连接。
- 温度、电压、电机驱动故障可观察（自研控制板阶段）。

## 非功能需求 / 验收

- V0.1：计算模型单元测试通过；单轴台架速度与方向符合设定。
- V0.2：双轴零位和限位可重复；机械碰撞风险有防范方案。
- V0.3：连续跟踪 30 分钟无失控/驱动过温（特定条件需记录）。
- V0.4：实星测定跟踪偏差、PHD2 导星 RMS、导星误差频谱，并发布原始数据。
- **不预设“亚角秒精度”已经实现**；控制分辨率不等于指向或导星精度。
