# 机械设计（待建模）

## 待参数化的结构

1. 极轴高度调整机构（适应实际纬度）和底座方位微调机构。
2. RA 总成：100:1 谐波减速器的尺寸/额定倾覆力矩校核、配套支撑轴承、输出法兰、同步带和电机座。
3. DEC 总成：独立支承、法兰、同步带、电机座、鞍座安装。
4. 电机电缆布线、旋转区域与限位方案、轴承预紧、防水防尘与服务通道。
5. 标准三脚架或固定柱接口（具体规格待定）。

## CAD 交付清单

- 参数化源文件（FreeCAD 或其他可编辑格式）。
- STEP 中立格式；装配图 PDF；单独打印件 STL；加工件工程图；紧固件表。
- 一张爆炸图和一份公差/装配顺序说明。

## 危害与验证

谐波减速器**不应被当成制动器**。当电机失电时是否反驱，应按实物、载荷重心和结构测试；必要时设计独立制动或配重。不能在人员或昂贵光学器材附近进行未防护的首次上电测试。核对负载力矩而非仅依赖“额定公斤数”。
