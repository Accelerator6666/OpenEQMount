# DfAM per-part review template (copy for each final STL)

- Part number / Git commit / CAD param revision:
- Intended use, load vectors, failure consequences:
- Material, producer, printer model, nozzle, extrusion width, layer, temperature, chamber, dry protocol:
- Print orientation: bed face; +Z direction; seam; photograph/slicer setup:
- Main stress relative to XY layers; potential interlayer separation/creep:
- Minimum wall, neck, boss edge distance, rib root fillet dimensions **measured in CAD**:
- Unsupported overhangs/bridges/hidden support traps after slicer inspection:
- Nominal vs printed dimensions and coupon calibration measurements:
- Metal fastener length, accessible nut/washer stack, tightening protocol, torque, thread depth:
- Assembly interferences, belt/pulley clearance, maintenance accessibility:
- Fit-test photos and slicer screenshots:
- Load testing protocol; static load, duration, thermal cycles, acceleration/vibration, deformation/creep:
- Independent fall restraint and emergency stop checks:
- Signoff: **Gate A digital pass / Gate B print-fit pending / Gate C load pending** (default)
- Verdict: **NOT AUTHORIZED FOR PAYLOAD** until justified evidence exists.
