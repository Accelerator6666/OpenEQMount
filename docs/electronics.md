# 电控开发（待原理图/PCB）

## V0 台架方案

- ESP32 + **已由 OnStepX 支持的主板**，先验证固件和驱动；FYSETC E4 仅作为候选，需要确认版本和固件支持。
- RA / DEC 两路 TMC2209（是否足够由实测电流、温升、加速转矩决定），后续可选择 TMC5160 的适配硬件。
- 两个零位传感器，必要的极限位传感器，手动停止按钮、熔断器/电源保护、线缆固定。
- 电机电源与逻辑电源分开评估；启停顺序、保护地、共地和接线防呆写入电气图。

## 自研 PCB（V2）

- KiCad 原生 `.kicad_pro`, `.kicad_sch`, `.kicad_pcb`；对外提供生产 Gerber、BOM 和贴片位号。
- 首版记录关键信号：STEP、DIR、ENABLE、UART/SPI、ALARM、HOME、LIMIT、E-STOP。
- 定义诊断面板：驱动电流、母线电压、温度、传感器状态、通信连接。
- 任何大电流、电压和热设计必须完成数据手册核对与样机测试后才可定版。
