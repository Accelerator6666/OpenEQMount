# OpenEQMount V0.5 — DfAM Adjustable Polar Wedge (Gate A, bench prototype)

**研发状态：Gate A 数字几何验证，仅供台架与装配设计，不得承载相机。**

本版本面向 3–5 kg / ≤500 mm 的长期开发目标，并不证明实际摄影载荷、刚度或跟踪精度。严格遵守 [DfAM 强制规范](dfam-design-standard.md)。

## 1. 基本机械路线

1. **全金属承力**：固定三脚架底板、可转动方位上板、纬度铰链金属耳、可倾斜 RA 固定端平台，以及 M8 金属调节螺杆/铰接头参考模型。
2. **FDM 只承担非承力用途**：左右护盖、纬度指针、方位刻度环、公差试片共 5 个可打印组件。PETG 为试装材料，并非野外承重材料。
3. **运动控制**：纬度调节 25–45° 的模型验证范围；方位定位弧槽 ±5°（运动需在实物上校核）。赤道仪的 RA 轴必须与平台法线一致，向北方向定义为负 X。
4. **关键金属紧固件**：Ø8.5 铰链过孔对应待选定的 M8 销轴，方位长孔对 M6 锁紧螺钉，中央 Ø10.5 为临时 M10 定位孔。这些尺寸不能替代具体供应商的轴、垫片、螺母和连接扭矩设计。
5. **非完整机械产品**：尚未设计可锁止的独立纬度扇形锁紧机构、认证的调节丝杠/止推装置、冗余金属防坠、限位装置、三脚架匹配法兰或安全停车位。

## 2. 参数、坐标与关键尺寸

| 参数 | 名义值 | 属性 |
|---|---:|---|
| 三脚架底座金属板 | 210 × 158 × 6 mm | 外形草案，非打印件 |
| 方位回转金属板 | 166 × 145 × 6 mm | 上板间隙初拟 2 mm，金属轴向支承待设计 |
| 纬度范围 | 25–45° | V0.5 几何模型验证，不等于机构行程承诺 |
| 方位范围 | ±5° | 两个 R58、Ø6.6 弧槽；需确认锁紧螺栓通达 |
| 固定铰链轴中心 | X=−61, Y=0, Z=29 mm | 金属 Ø8 转轴参考 |
| 默认纬度 | 35° | 默认生成角度，可参数化 |
| 螺杆参考 | Ø8 mm | 仅空间包络，无螺纹、轴承或额定推力 |
| V0.5 打印部件 | 5 件 | 最大成型方向 XY 外形 ≤220×220 mm |
| 金属部件 | 10 件 | 需工程复核后外协制造/采购 |

**重要运动学定义：**顶部金属平台自水平上扬 `倾角 = 90° − 当地纬度`，所以在 RA 轴垂直平台且指向北方的假设下，其仰角为当地纬度。测量的当地纬度必须按实际观测地点设定，默认 35° 并非固定使用地点。

**名义螺杆端点距离**（两端销轴中心，单位 mm；自动生成的 manifest 精确值为准）：

| 纬度 | 端点距离（约） |
|---:|---:|
| 25° | 122 mm |
| 35° | 103 mm |
| 45° | 84 mm |

以上是空间距离，不是丝杠的有效行程、丝杆承载能力或对应的运动行程。实际丝杠需以工况设计长细比、屈曲裕量、止推轴承、间隙补偿、误碰撞和防旋出止挡。

## 3. 与 V0.4 的正确装配边界

**禁止将 V0.4 的 `v04_ra_output_plate_METAL`（赤经旋转输出端）固定到 V0.5 极轴座。** 这样会锁死或破坏 RA 旋转。V0.5 上板采用可调整的临时 4 孔接口（X=−43/+45，Y=±45），不得据此推断已经兼容任何谐波减速器固定机壳。需要独立设计 **RA 减速器固定机壳 / 主轴承承载座转接板**，并明确旋转侧与静止侧的力流路径。

## 4. DfAM 和零件审核

- 所有 STL 已旋转至 XY 平放、底面 Z=0；仍须确认切片材料/喷嘴/壁数/桥接/层间缺陷。
- 左右护盖不承担任何铰链、减速器或摄影器材载荷，不得夹入金属预紧路径。
- 量具和刻度仅辅助检查，不能作为极轴校准精度指标；打印收缩及翘曲需要实测。
- 主承力结构为金属件，不允许将金属 STEP 转成塑料 STL 用作承重替代。
- Gate A: 数字 CAD、网格封闭及接口运动学；Gate B: 切片/尺寸/实装；Gate C: 静态、动态、热循环、蠕变、防坠试验和安全验收。

## 5. 必须解决的开放问题（发布 Gate B/C 前）

1. 金属铰链轴和叉耳的真实配合公差、双剪结构、轴向止退、销轴弯曲、轴承/衬套选择和润滑。
2. 金属上/下板实际支承面、轴向/径向推力路径，M10 轴心不能独自承担倾覆载荷。
3. 两条方位弧槽的可达性、旋转与锁紧顺序、方位顶丝受力、夹紧后滑移风险。
4. 纬度升降丝杠的额定推力、屈曲、球面端、回程间隙及防脱落；另加**独立金属锁紧及限位**，防止突然落下。
5. RA 固定端安装板及谐波减速器选定型号的实际孔系和锁紧力矩，不能误用 RA 输出端。
6. 实际三脚架连接孔型/螺栓等级、防扭旋转锁、带金属安全绳的冗余防坠结构。
7. 在纬度 25/35/45、方位 −5/0/+5 的各种组合下完成全机构干涉、工具可达性、配重/线束检查。
8. 实际 3–5 kg 器材重心到倾斜轴的力矩计算、风荷载和运输冲击，不能使用标称载荷直接代替设计工况。

## 6. 复现命令

```bash
python -m pip install 'cadquery>=2.5,<3' trimesh pytest
python hardware/cad/generate_v05.py --latitude 35 --out hardware/cad/v05_generated
python -m pytest -q tests/test_v05_polar_wedge.py
python tools/dfam_gate_v05.py --dir hardware/cad/v05_generated --report hardware/cad/v05_generated/dfam-gate-report.json
```
