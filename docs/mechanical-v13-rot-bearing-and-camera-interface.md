# OpenEQMount V1.3 — ROT 轴承内圈保持、相机夹具转接基准与独立防坠布局（Gate A）

**状态：仅数字几何原型；不可制造定版、不可安装相机、不可通电。** 继承 V1.2 的 DEC–ROT 金属桥架和独立机械限位概念。保留 RA/DEC/ROT 三轴与纬度 25–45° 规划区间。

## 1. 轴向尺寸链（局部 ROT +Z，毫米）

| 部件 | 轴向参考 | 说明 |
|---|---|---|
| 金属转轴一体下肩 | 3–7 | 金属整体加工构想，OD45，仅作为下侧轴向挡肩 |
| 候选 6808 轴承 A | 7–14 | 40×52×7，安装配合和允许力矩均未验证 |
| 轴承内圈隔套 | 14–37 | 23 mm，OD45 / ID40.2 **参考值** |
| 候选 6808 轴承 B | 37–44 | 两轴承轴向基准相距 30 mm |
| 上端锁紧螺母示意 | 44–50 | OD47，ID37.7；与轴身名义 OD38 接触属于**未建模的螺纹区域** |
| 防松垫片示意 | 50–51.5 | 未锁键、未机械折片、**不构成有效防松** |
| 相机转接板 | 67–75 | 输出法兰 PCD88 6×M4 对接候选；另设 2×M6、间距 60 mm 候选安装孔 |

- 6808 内圈的真实有效端面宽度、密封圈避让、外圈薄挡肩，以及所需的负游隙/预紧量均**未取得厂商具体图纸并验证**。
- 外圈仍使用 V1.2 的细薄保持参考件（内孔径 50/外径52、径向有效厚约 1 mm），**不是可以发包加工的结构**。
- 轴上的外螺纹、公差、应力集中圆角、螺母齿形、防松折片、拧紧扭矩、工具空间以及实际力矩/冲击验算全部缺失。STEP 的圆柱套筒不能当作螺纹连接。
- 两只深沟球轴承并非自动获得合格的倾覆力矩刚性。必须根据相机+镜头重心偏距和 3–5 kg 研发载荷目标选择更适合的轴承组合，计算弯矩、疲劳、倾角与镜头光轴漂移。

## 2. 可更换金属相机夹具接口

- V1.3 用真实金属转接板替换 V1.1 的空白片：输出端名义 6×M4 / PCD 88；相机夹具 **2×M6、孔距 60 mm 仅为概念孔位**，不得据此购买或打孔。
- Arca-Swiss Classic 原版燕尾标称 38 mm，但不同品牌与型号的夹具固定孔位、夹片宽度、反脱销不同。夹具必须先选定并测量 OEM 图纸，不允许假设任意 Arca 夹具可直接装配。
- 镜头脚承力优先考虑**具体镜头的金属脚和带防脱销的商用金属夹具**。旋转器输出法兰/紧固件的真实强度必须在 Gate C 完整验证。

## 3. 独立防坠与线缆

- 保留 V1.2 固定端金属锚点；在 V1.3 中用**粉红色悬空参考件**表明相机侧锚点必须**真正连接到相机笼或镜头环金属部位**，而不是再次连接同一块快装板。这个锚点当前悬空，不能被认为已接好。
- `manifest.json` 包含 ROT -150° 到 +150°、每 30° 一个的固定-旋转锚点**直线距离参考**，不能代替柔性钢索碰撞、绕线、打结、拖曳或断裂验证。
- 220 mm 是未确认线缆空间演示值，**不是采购长度，不是推荐钢索长度，不是安全余量**。实际路线可能与 RA/DEC 桥架、硬止挡、线缆和镜头发生干涉。
- 独立防坠需要经过锚点材料、钢索和扣具额定工作载荷 (WLL)、断裂安全系数、紧固防松、跌落距离、扭力以及最坏姿态的整套试验。

## 4. DfAM：仅允许两件 PETG 非承力打印检具

- `v13_NONLOAD_CAMERA_TWO_M6_LOCATOR_GAUGE_PRINT_FLAT.stl`：60 mm 孔距几何参考；仅用于卡尺/试装，不可代替金属夹具板。
- `v13_NONLOAD_SHAFT_NUT_CLEARANCE_GAUGE_PRINT_FLAT.stl`：孔隙几何参考，不可当承载隔套或螺母。
- 两件均平放 Z=0，无承力打印螺纹；实际打印方向、材料收缩、孔隙和悬垂仍需 Gate B 观察与测量。

## 5. 复现与审查

```bash
python -m pip install 'cadquery>=2.5,<3' pytest trimesh matplotlib
python -m pytest -q tests/test_v13_rot_retention.py
python hardware/cad/generate_v13_rot_retention.py --out hardware/cad/v13_generated
python tools/dfam_gate_v13.py --dir hardware/cad/v13_generated --report hardware/cad/v13_generated/dfam-gate-report.json
python tools/render_v13.py
```

可用 FreeCAD 打开 `OpenEQMount_V13_THREE_AXIS_RETENTION_DATUM_CONCEPT_UNQUALIFIED.step`。金属零件 `.step` 用于接口讨论，2 件非承力 `.stl` 用于打印公差验证。

## 6. V1.4 阻塞任务

1. 获取**准确零件 SKU**：6808 供应商样件尺寸、公差图、轴肩接触面；选定真实相机/镜头及金属夹具 OEM 孔位、镜头脚防旋转定位与重心。
2. 将轴承支承架构由尺寸占位升级为经弯矩、刚度与轴向载荷论证的真实结构；设计真实螺纹、锁紧件、机械止退与外圈保持面。
3. 将相机笼或镜头固定脚的安全锚点真正做成与快装连接**独立**的承力链，并通过整体防坠跌落试验。
4. 限位开关冗余、线束实际柔性扫掠、±150° 软件行程与 ±160° 机械硬挡检查；RA/DEC/ROT 全姿态干涉检查。
5. Gate B 实物打印及测量；Gate C 静态弯矩、重复定位误差、温度、紧固件振动、碰撞、停机保持、跌落及长时耐久测试。
