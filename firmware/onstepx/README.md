# OnStepX integration

Upstream: https://github.com/hjd1964/OnStepX

Do **not** commit an unmodified copy of upstream firmware into this repository. First select a verified board/pinmap, driver type, correct gear ratio, then record tested configuration, toolchain, branch or commit ID here. Observe upstream GPL obligations if distributing derivatives.

Initial mathematical assumptions are in `tools/motion_math.py`. These are not complete firmware configurations.
